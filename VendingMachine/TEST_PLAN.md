## Parameterized Testing Strategy

The VendingMachine test suite will use a parameterized test for `insertMoney(double amount)`. The values `0.01`, `0.10`, `1.00`, `10.00`, `100.00`, and `1000.00` were selected as representative valid inputs across increasingly large monetary values. These values use the valid `amount >= 0` equivalence class and verify that each inserted amount increases the balance by that amount.

Boundary behavior around the minimum valid amount will also be tested using `-0.01`, `0.00`, and `0.01`. These values represent immediately below, exactly at, and immediately above the boundary specified by the `insertMoney()` precondition.
